# 清宮ゼミ Webサイト

西南学院大学 外国語学部「清宮ゼミ」の紹介サイトです。HTML・CSS・JavaScriptだけで作られており、GitHub Pagesでそのまま公開できます。

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作成します（例：`kiyomiya-seminar`）。
2. このフォルダ内のすべてのファイルと `assets` フォルダをアップロードします。
3. リポジトリの `Settings` → `Pages` を開きます。
4. `Build and deployment` の Source を `Deploy from a branch` にします。
5. Branchを `main`、フォルダを `/(root)` にして `Save` を押します。
6. 数分後、表示されたURLからサイトを確認できます。

## 内容を変更する場所

- 文章・見出し：`index.html`
- 色・レイアウト：`style.css` 冒頭の `:root`
- メニュー・アニメーション：`script.js`
- 教授写真の元画像：`assets/seminar-guide-2026.jpeg`
